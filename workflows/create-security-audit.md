# Анализ безопасности по ГОСТ 5131

Для выполнения этого задания тебе нужно следовать детальному плану, который находится в файле `.kilocode/workflows/gost5639/5131/plan.md`.

## Инструкция по выполнению:

1. **Прочитай детальный план**:
   - Используй команду `read_file` для чтения файла `.kilocode/workflows/gost5639/5131/plan.md`
   - Внимательно изучи все разделы плана, особенно:
     - Цели анализа
     - Требования ГОСТ
     - Структуру итогового документа
     - Критерии оценки

2. **После прочтения плана, выполни анализ репозитория** строго следуя инструкциям из `plan.md`

3. **Создай итоговый документ** в корне репозитория с названием `security-analysis-{repo-name}.md` Используй для этого write_file() или если такого инструмента нет bash.
