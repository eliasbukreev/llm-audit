# Анализ безопасности по ГОСТ 5131 (из удалённого репозитория)

Этот workflow анализирует репозиторий по указанному URL: клонирует его, выполняет анализ по ГОСТ и сохраняет результат в папку `mcp-server-dib/results/`. Для работы с файлами используется MCP server-filesystem.

## Структура файлового хранилища

| Назначение       | Путь                                                                 |
|------------------|----------------------------------------------------------------------|
| План анализа     | `mcp-server-dib/docs/plans/Анализ текущего состояния процессов разработки безопасного ПО.md` |
| Пример результата| `mcp-server-dib/docs/templates/Анализ текущего состояния процессов разработки безопасного ПО.md` |
| ГОСТ Р 56939-2024| `mcp-server-dib/docs/standarts/ГОСТ Р 56939— 2024.md`                               |
| Итоговые отчёты  | `mcp-server-dib/results/security-analysis-{repo-name}.md`                            |

## Инструкция по выполнению

### 1. Запросить адрес репозитория

Спроси пользователя URL репозитория для анализа (GitHub, GitLab и т.п.). Примеры форматов:
- `https://github.com/org/repo-name`
- `https://github.com/org/repo-name.git`
- `https://gitlab.com/org/repo-name`

Извлеки имя репозитория из URL (например, `repo-name` из `https://github.com/org/repo-name.git`).

### 2. Клонировать репозиторий

- Создай папку `repos-for-analysis`, если её нет.
- Выполни: `git clone <url> repos-for-analysis/<repo-name>`
- Если клонирование не удалось — сообщи пользователю об ошибке и не переходи к следующим шагам.

### 3. Прочитать план и выполнить анализ

- Прочитай детальный план из `mcp-server-dib/docs/plans/Анализ текущего состояния процессов разработки безопасного ПО.md`
- Ознакомься с примером: `mcp-server-dib/docs/templates/Анализ текущего состояния процессов разработки безопасного ПО.md`
- Выполни анализ **внутри** `repos-for-analysis/<repo-name>/`, следуя инструкциям из плана
- Создай итоговый документ в `mcp-server-dib/results/security-analysis-<repo-name>.md` (папку `results/` создать при необходимости)

### 4. Удалить репозиторий

Удали папку `repos-for-analysis/<repo-name>` (через `rm -rf` или аналог), чтобы освободить место.
